# 茄子迭代需求 V2.1.3 · 设计交付版

茄子代售（www.qiezi.com / m.qiezi.com）V2.1.3 迭代的产品需求文档，供 UI 出图使用。

在线预览：https://<你的 GitHub 用户名>.github.io/qiezi-v2.1.3/

## 本轮迭代范围

| 序号 | 需求 | 涉及端 | 优先级 |
|------|------|--------|--------|
| 一 | 优惠券发放条件组合逻辑调整（纯后台，无页面改动） | 纯后台 | P0 |
| 二 | 增加账号商品地区与装备筛选（账号地区 + awm子弹） | www + m | P0 |
| 三 | 增加商品上传字段：方便上号时间（含列表与详情展示） | www + m | P1 |
| 四 | 上传商品流程中提高押金样式层级（标红） | www + m | P1 |
| 五 | 商品列表与订单详情补充核心交易信息（比例、道具明细；含买家/卖家两种视角） | www + m | P1 |

## 文档说明

- 本文为**设计交付版**，聚焦页面改动、信息层级与交互原型，供 UI 出图使用。
- 文档**不含**设计规范、色值规范与技术实现方案；具体视觉样式沿用两端既有设计体系。
- 五条需求均覆盖 www（PC 主站）与 m（移动端入口）两端，两端需**分别出图**。
- m 站仅在安卓手机上可正常访问，桌面浏览器打开会跳转 www 站，验收需用手机或安卓模式。

## 交互原型

文档内嵌可交互原型，共 5 组：

1. **原型 1** · 优惠券条件组合方式对照（调整前/后命中人群差异）
2. **原型 2** · 商品列表筛选（账号地区省市联动 + awm子弹档位）
3. **原型 3 / 3-2** · 上架表单新增"方便上号时间" + 两端列表与详情展示样式
4. **原型 4** · 上架表单押金样式层级（调整前/后对照）
5. **原型 5** · 订单列表 → 订单详情（www/m 站切换，买家/卖家两种视角）
